# Конверт — антифрод по метаданным вызова

Решение кейса Nexign «Антифрод без прослушки» (хакатон «Телеком будущего 2026», МТУСИ).

Система находит мошеннические номера по одному «конверту» вызова — кто, кому, когда и сколько
секунд. Содержимое разговоров не используется. Каждое решение раскладывается на факторы с вкладом
в баллах, а автоблокировка считается отдельно от балла.

## Результат на выгрузке 1–5 октября 2026

| | |
|---|---|
| Записей CDR | 2 353 333 в 471 файле, 1 901 строка с ошибками формата исправлена |

## Быстрый старт

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt        # Linux/macOS: .venv/bin/pip

# 1. расчёт: CDR → ответ и данные для интерфейса
.venv/Scripts/python -m konvert.pipeline --cdr data/cdr_out --out outputs

# 2. интерфейс и API
.venv/Scripts/python -m uvicorn konvert.api:app --port 8000   # http://127.0.0.1:8000, документация API: /docs

# 3. самодостаточная страница без сервера (dist/index.html)
.venv/Scripts/python -m konvert.webbuild --out dist

# тесты
.venv/Scripts/python -m pytest tests -q
```

На Windows достаточно запустить `run_demo.bat`. Выгрузку (`CDR_*.cdr`) нужно положить в `data/cdr_out/`.

## Три вещи, которые отличают решение

**Объяснимость встроена в расчёт.** Балл — это сумма вкладов факторов, а не выход модели, к которому
объяснение подбирают задним числом. «792 вызова за 2,4 ч: +25», «100% вызовов — сброс на 0–2 секунде: +35».
Для легального источника карточка показывает обе стороны: что настораживает и что снимает подозрение.

**Автоблокировка отделена от балла.** Она разрешена только для схем, у которых нет легального применения
(Wangiri, робот, SIM-box, клон SIM), при балле от 90 и минимум трёх независимых факторах — это 234 номера
из 621. По остальным система советует, решает человек. Вызов на 112, 101–104 проходит до любого скоринга,
даже если звонящий уже в чёрном списке.

**Проверено тремя способами.**
1. Ни один из 379 распознанных легальных источников не попал в ответ.
2. Потоковые правила на скользящем окне ловят Wangiri через 20 вызовов (медиана 3,7 минуты) и робота
   через 10 вызовов (48 секунд) и ни разу не срабатывают на посторонних номерах. Это 96% и 99% вызовов схем.
3. Модель CatBoost обучена на самих находках правил, но видит только общий профиль номера — без графа
   связей и без правил схем. На отложенных группах она воспроизводит 353 находки из 353 (покрытые
   353 номера из 621: порог ≥20 исходящих и шесть «профильных» ролей) и не называет фродом ни один
   легальный источник. Это проверка не правильности, а того, что правила выражаются языком профиля;
   «экзамен на новую схему» показывает, какие схемы видны по профилю, а какие — только по графу.
